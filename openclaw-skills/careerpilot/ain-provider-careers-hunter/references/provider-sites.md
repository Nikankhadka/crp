## Common ATS Platforms

### Workday
- Used by: Bupa, UnitingCare, Estia
- Application flow: Create account → Upload resume → Answer questions → Submit
- Resume format: PDF or DOCX
- Cover letter: Often optional

### iCIMS
- Used by: Regis, Right at Home
- Application flow: Create account → Fill form → Upload documents → Submit
- Resume format: PDF or DOCX
- Cover letter: Usually required

### SmartRecruiters
- Used by: Opal Health
- Application flow: Quick apply or full application
- Resume format: PDF or DOCX
- Cover letter: Optional

### SuccessFactors (SAP)
- Used by: HammondCare
- Application flow: Create account → Fill form → Upload documents → Submit
- Resume format: PDF or DOCX
- Cover letter: Often required

## Application Tips

### Provider-Direct Benefits
- Jobs may not be advertised elsewhere
- Faster response times
- Better chance of interview (less competition)
- Salary packaging (not-for-profit providers)

### Application Strategy
1. Apply directly on provider site first
2. If job also appears on Seek/Indeed, apply there too
3. Note in tracker which application was first
4. Follow up with facility directly if no response in 7 days

## Facility-Specific Notes

### Shift Patterns
- **Morning**: 6:30am - 2:30pm
- **Afternoon**: 2:30pm - 10:30pm
- **Night**: 10:30pm - 6:30am
- **Sleepover** (community): 10pm - 6am (sleep, wake for checks)

### Role Variations
- **AIN**: Assistant in Nursing (medication, clinical tasks)
- **PCW**: Personal Care Worker (ADLs, no medication)
- **Support Worker**: Disability support (community-based)
- **Team Leader**: Senior role, supervising care staff

### Certifications to Highlight
- Certificate III in Individual Support (Ageing/Disability)
- First Aid
- CPR
- Police Check
- NDIS Worker Screening
- Driver's Licence (for community roles)
